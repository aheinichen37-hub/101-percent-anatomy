# Notes for Claude

- Andrew talks in raw, rambling thoughts. When a message mentions a side idea (even in passing), add it to `IDEAS.md` under **Open** with the date, and check `IDEAS.md` before starting new work so parked ideas resurface when they fit.
- Push new ideas to `IDEAS.md` on GitHub automatically whenever a conversation ends or a brainstorm wraps up, without waiting to be asked.
- Version every release with an incrementing number (2.4, 2.5, ...) in the page footer, the CSS comment and `README.md`.
- Run the regression test (regress 2.1.0, `tools/regress.py` in this repo is the source of truth; the claude.ai project still holds the old v1 copy, `claude/101-anatomy-regression-test.py`, which is out of date) on every new version before pushing. Use `python3 tools/regress.py index.html --quick` (about 6 s) while building and `--full` (about 40 s) before every release push. `--units 3,11` replays chosen units and `--changed` replays only decks whose questions or pictures changed since the last passing run. Commit `tools/.regress-cache.json` with each release; it is what `--changed` compares against. Version the test itself with an incrementing number when it is revised.
- Run the groups scanner (`python3 tools/groups.py`, v1.0.0, about 3 s) before every release push: it lists multiple-choice questions with weak wrong choices. Hand fixes go in `tools/groups-overrides.json`, applied with `--apply`. The picker, group rules and scanner are meant to be reused for other courses (swap `GROUP_HOSTS` in `index.html` and the overrides file).
- Also run the correctness test (`python3 tools/correctness.py index.html`, about 13 s, v1.0) before every release push. It checks every accepted answer grades correctly, wrong answers fail, picture files/highlights are sound and typing works; fix errors, review warnings. Version it with an incrementing number when revised.
- Card IDs are locked (3.8.1): most are a deck line's position, and saved progress, tips and picture overrides key on them. Add new cards at the end of a deck, retire a card by starting its line with `~`, never insert, delete or reorder lines. `python3 -m pytest tools/tests/test_card_ids.py` guards this; after a real answer fix or a new card run `python3 tools/card_ids.py --update` (v1.0.0) and read its summary.
- Identification pictures (3.8.3): hand fixes go in `tools/id-fixes.json` (white boxes over leftover labels, a moved spot) and are applied with `python3 tools/idimg/patch_pics.py` (v1.0.0; rebuilds from the 3.8.2 originals, fetching that commit if a shallow clone lacks it). Before a release that touches pictures, run `python3 tools/idimg/scan_pics.py` (v1.0.0, about 80 s): "answer" and "label" hits must be zero or known OCR noise, then look at the flagged ones by eye.
